# カスタムウェイクワード「オッケーセバス」テスト結果

## 問題

日本語のカスタムウェイクワード「オッケーセバス」（.ppnファイル）を使用しようとすると、以下のエラーが発生：

```
Keyword file (.ppn) and model file (.pv) should belong to the same language. 
File belongs to `ja` while model file (.pv) belongs to `en`.
```

## 原因

Porcupine v3.0.5では、日本語モデルファイル（.pv）が自動的にインストールされない、または正しく検出されない。

## 調査結果

1. **デフォルトモデル**: 英語（en）のモデルのみがインストールされている
2. **日本語モデル**: 別途ダウンロードまたは指定が必要
3. **自動検出**: model_pathパラメータを省略しても、言語の自動検出は機能しない

## 解決策（調査中）

### 可能性1: 日本語モデルの手動ダウンロード
Picovoice Consoleから日本語モデルファイルをダウンロードして、明示的に指定する必要があるかもしれない。

### 可能性2: Porcupineバージョンの問題
より新しいバージョンのPorcupineでは、多言語サポートが改善されている可能性がある。

### 可能性3: 初期化パラメータの調整
特定のパラメータ組み合わせで日本語モデルが自動ダウンロードされる可能性がある。

## 次のステップ

1. Picovoice公式ドキュメントで日本語モデルの扱い方を確認
2. Picovoice Consoleで日本語モデルファイルの入手方法を調査
3. 代替案として、英語のカスタムウェイクワードを作成してテスト

## 暫定的な回避策

現時点では、以下の方法でテストを継続できる：

1. 英語の組み込みキーワード（"picovoice", "alexa"等）を使用
2. 英語版のカスタムウェイクワード（"OK Sebastian"等）を作成
3. 日本語モデルの入手方法が判明するまで、英語版で開発を進める
