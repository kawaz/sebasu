# Sebasu

[English](./README.md)

Sebasu は各部屋の ESP32-S3 + XVF3800 サテライトと Mac サーバで動く、ローカル完結の自作音声アシスタントです。音声入力からウェイクワード検出 → 発話区間検出（VAD）→ 音声認識（STT）→ ローカル LLM とツール呼び出し → 音声合成（TTS）→ 再生へつなぎます。運用時にクラウドサービスを必要としません。

すべてのコンポーネントにストリーミング入出力インターフェースを定め、エンジンを独立したアダプタとして差し替えます。Linux サーバ対応は裁定待ちです。

**現状:** 設計段階。候補エンジンと統合経路の PoC は実測済みですが、複数部屋のアシスタント本体とサテライトのファームウェアは未実装です。
